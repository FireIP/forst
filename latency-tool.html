🔁 Approach 1 — Loopback (pixel marker)
  1. The Source Canvas draws animated content plus a large black/white square in the top-left corner that toggles state every N ms (configurable).
  2. Exactly when the state changes, t_src = performance.now() is recorded.
  3. The canvas stream is fed into a local RTCPeerConnection pair (pc1 → pc2), passing through the chosen codec's encoder and decoder entirely in the browser.
  4. A requestAnimationFrame loop reads the remote <video> into a tiny <canvas> each frame, computes average luminance of the marker region, and detects the transition.
  5. When detected, t_play = performance.now() is recorded and latency = t_play − t_src is added to the sample set.
  6. Statistics (mean, median, p95, p99, stddev) and a histogram are updated live.

This measures: encoder + RTP packetise + decoder + rAF render latency — the full browser WebRTC pipeline without network.

📡 Approach 2 — External stream (getStats)
  1. Enter your OME WebRTC URL (e.g. wss://host:3334/app/stream). OvenPlayer connects and plays the stream.
  2. The tool monkey-patches RTCPeerConnection to capture the underlying PC and calls pc.getStats() every 500 ms.
  3. Key stats displayed: jitter buffer delay, avg decode time per frame, FPS, packet loss, NACK count, network RTT, and estimated playout latency.
  4. Optional pixel detection: configure the marker region to match where OBS injects a toggling B/W overlay in the scene. The tool logs each transition time.
  5. Optional source sync: load the included Python script in OBS. It toggles the OBS marker and serves {"state":N,"tSrc":ms} events over local HTTP, with tSrc as Unix epoch milliseconds. The page converts these timestamps to its local performance.now() time basis.
🧮 Statistics explained
MeanAverage latency over all samples.
Median50th percentile — robust to occasional spikes.
p95 / p9995th / 99th percentile — worst-case tails.
StdDevJitter: how much latency varies between samples.
Jitter buffer delay From getStats: jitterBufferDelay / jitterBufferEmittedCount × 1000. The average time frames spend in the jitter buffer before playback.
Est. playout latency Date.now() − estimatedPlayoutTimestamp. Rough estimate (requires sender/receiver clocks to be NTP-synced).
🛠 OBS marker setup (for Approach 2)

Run OBS and this page's browser on the same computer, then set up one OBS scene and load this helper directly in OBS:

  1. In the scene you want to measure, add two Color Sources: name them G2G Latency Marker White and G2G Latency Marker Black. Set them to white and black, give both a size of 200×200 px, and place both at the top-left corner above the video. Start with White visible and Black hidden.
  2. In OBS, open Tools → Scripts. In the Scripts tab, click + and select Python Settings if needed. Point OBS to a compatible Python installation as instructed in that dialog (OBS's bundled Python is recommended).
  3. Copy the script below to a file named g2g_marker.py. Back in Scripts, click + and select that file. No pip packages, WebSocket server setting, or password are needed.
  4. Make the target scene the current program scene. The script starts toggling the two named sources and serves timestamp events at http://127.0.0.1:9090/events. Keep OBS and the script running while measuring.
Copyable OBS Python script (OBS API + Python standard library) 
import collections
import json
import threading
import time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import parse_qs, urlparse

import obspython as obs

WHITE_MARKER_NAME = "G2G Latency Marker White"
BLACK_MARKER_NAME = "G2G Latency Marker Black"
INTERVAL_MS = 1000
HTTP_HOST = "127.0.0.1"
HTTP_PORT = 9090

events = collections.deque(maxlen=256)
event_condition = threading.Condition()
event_id = 0
http_server = None
http_thread = None
missing_source_reported = False
timer_started = False


class MarkerRequestHandler(BaseHTTPRequestHandler):
    def send_cors_headers(self):
        self.send_header("Access-Control-Allow-Origin", "*")
        self.send_header("Access-Control-Allow-Methods", "GET, OPTIONS")
        self.send_header("Access-Control-Allow-Headers", "Content-Type")
        if self.headers.get("Access-Control-Request-Private-Network") == "true":
            self.send_header("Access-Control-Allow-Private-Network", "true")

    def do_OPTIONS(self):
        if urlparse(self.path).path != "/events":
            self.send_error(404)
            return
        self.send_response(204)
        self.send_cors_headers()
        self.send_header("Access-Control-Max-Age", "600")
        self.end_headers()

    def do_GET(self):
        if urlparse(self.path).path != "/events":
            self.send_error(404)
            return
        try:
            after = int(parse_qs(urlparse(self.path).query).get("after", ["0"])[0])
        except ValueError:
            self.send_error(400, "Invalid event cursor")
            return

        with event_condition:
            available = [event for event in events if event["id"] > after]
            if not available:
                event_condition.wait(timeout=15)
                available = [event for event in events if event["id"] > after]

        body = json.dumps({"events": available}).encode("utf-8")
        self.send_response(200)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(body)))
        self.send_header("Cache-Control", "no-store")
        self.send_cors_headers()
        self.end_headers()
        try:
            self.wfile.write(body)
        except (BrokenPipeError, ConnectionResetError):
            pass

    def log_message(self, _format, *_args):
        pass


def publish_event(state, timestamp):
    global event_id
    with event_condition:
        event_id += 1
        events.append({"id": event_id, "state": state, "tSrc": timestamp})
        event_condition.notify_all()


def toggle_marker():
    global missing_source_reported
    scene_source = obs.obs_frontend_get_current_scene()
    if scene_source is None:
        return
    try:
        scene = obs.obs_scene_from_source(scene_source)
        white_item = obs.obs_scene_find_source(scene, WHITE_MARKER_NAME)
        black_item = obs.obs_scene_find_source(scene, BLACK_MARKER_NAME)
        if white_item is None or black_item is None:
            if not missing_source_reported:
                scene_name = obs.obs_source_get_name(scene_source)
                missing = []
                if white_item is None:
                    missing.append(WHITE_MARKER_NAME)
                if black_item is None:
                    missing.append(BLACK_MARKER_NAME)
                obs.script_log(
                    obs.LOG_WARNING,
                    "Marker toggle skipped: current program scene %r is missing %s. Add each "
                    "as a Color Source directly to this scene (not only to another scene or group)." %
                    (scene_name, ", ".join(repr(name) for name in missing)),
                )
                missing_source_reported = True
            return
        missing_source_reported = False
        state = 0 if obs.obs_sceneitem_visible(white_item) else 1
        timestamp = time.time() * 1000
        obs.obs_sceneitem_set_visible(white_item, bool(state))
        obs.obs_sceneitem_set_visible(black_item, not bool(state))
        publish_event(state, timestamp)
    finally:
        obs.obs_source_release(scene_source)


def script_description():
    return "Toggles the G2G Latency Marker source and serves local timestamp events."


def script_load(_settings):
    global http_server, http_thread, timer_started
    try:
        http_server = ThreadingHTTPServer((HTTP_HOST, HTTP_PORT), MarkerRequestHandler)
        http_server.daemon_threads = True
        http_thread = threading.Thread(target=http_server.serve_forever, daemon=True)
        http_thread.start()
        obs.timer_add(toggle_marker, INTERVAL_MS)
        timer_started = True
        obs.script_log(
            obs.LOG_INFO,
            "G2G marker sync ready at http://%s:%s/events" % (HTTP_HOST, HTTP_PORT),
        )
    except OSError as error:
        http_server = None
        obs.script_log(obs.LOG_ERROR, "Could not start G2G marker server: %s" % error)


def script_unload():
    global timer_started
    if timer_started:
        obs.timer_remove(toggle_marker)
        timer_started = False
    if http_server is not None:
        http_server.shutdown()
        http_server.server_close()

After loading the script, open the External Stream tab, enable pixel detection and source-time sync, and connect to the URL above. Set the marker region to X/Y 0%; adjust W/H to cover the marker in your decoded video. Use an OBS browser on the same computer as OBS: the helper listens only on 127.0.0.1, so its URL is local to that computer. The helper does not connect to OBS's WebSocket server.

If the browser reports a network error, check that this browser is on the OBS computer and open http://127.0.0.1:9090/events?after=0 in a new tab. A JSON response (including an empty events list) means the local server is reachable. If OBS logs a missing-source warning, add the exact named sources to the program scene shown in that warning. If OBS reports Python unavailable, configure it in Tools → Scripts → Python Settings and reload the script.
